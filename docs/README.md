## Я пользователь: хочу спрашивать свою 1С

## Моя конфигурация

- [Бухгалтерия предприятия 3.0](CONFIG-ACCOUNTING.md) — полная поддержка: аналитика по счетам и запись документов.
  - [Настройка учёта](ACCOUNTING.md) — другой план счетов и виды операций (например, Бухгалтерия для Беларуси).
  - [Счета расчётов](SETTLEMENTS.md) — настройки счетов расчётов для договора, контрагента, группы.
- [Управление торговлей 11](CONFIG-TRADE.md) — остатки, продажи с розницей, расчёты с партнёрами, цены; запись цен,
  справочников, склада, денег, продаж и закупок.
- [Комплексная автоматизация 2 и ERP 2](CONFIG-KA-ERP.md) — что должно работать; на живой базе не проверено.
- [Поддержка по конфигурациям](SUPPORT.md) — каждый инструмент в Бухгалтерии и в УТ: проверено вживую, отказ по
  замыслу или только тесты.
