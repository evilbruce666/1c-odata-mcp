# Локальная модель: что вы получаете и чем за это платите

Коннектор отдаёт модели то, что вернула 1С: названия, суммы, ИНН, расчётные счета, ФИО. С облачной моделью всё это
уходит её провайдеру. С локальной (LM Studio, Ollama) остаётся в вашей сети. Плата за это — время ответа и меньший
набор инструментов. Сколько именно, я померил, чтобы вы не узнавали это уже после настройки.

## Сколько ждать ответа

Пять вопросов, какие задаёт руководитель: сколько денег, кто должен, крупнейшие покупатели, закрыт ли месяц и
короткая сводка из трёх частей. По три прогона на каждый вопрос, замер 26.11.2026.

| Что отвечало | Медиана | Быстрее всего и дольше всего |
|---|---|---|
| Claude Sonnet 5.5 (Claude Code 2.1.330) | 4,9 с | 3,6 – 12,6 с |
| gpt-6-luna, effort medium (Codex CLI 0.171.0-alpha) | 10,9 с | 9,0 – 16,3 с |
| Qwen3.5-9B Q4_K_M в LM Studio 0.4.29, Mac с M1 Pro и 16 ГБ памяти | 20,7 с | 13,9 – 75,3 с |

Все 45 ответов содержали нужные цифры.

У локальной модели:

- простой вопрос — один инструмент и ответ — занял 14–29 с. Исключение — самый первый запрос после загрузки модели:
  75 с на тот же вопрос про деньги, дальше 14–18 с;
- сводка, где нужно несколько инструментов подряд, — 59–75 с. У Claude на тот же вопрос уходило около 8 с, у Codex —
  около 15 с.

## Что в этих цифрах есть, а чего нет

- **1С в замере нет.** Вместо неё — маленький тестовый MCP-сервер с выдуманными данными, одинаковыми для всех: без
  сети и без базы. Это время клиента и модели. Настоящая 1С добавляет своё поверх: на большой базе отчёт за год
  считается десятки секунд.
- **Запускались программы командной строки**, а не окна ChatGPT, Claude и LM Studio. В окне будет чуть иначе.
- **Это один компьютер и одна локальная модель.** На более мощном железе или с другой моделью цифры будут другими.
  Версии облачных моделей и скорость сервисов меняются, так что относитесь к таблице как к порядку величин, а не как
  к рейтингу.
- Вопросы простые и составлены так, чтобы модели было с чем работать. Сложный анализ на локальной модели я не мерил.

## Что нужно, чтобы локальная модель справилась

- **Урезать набор инструментов.** Все 91 инструмент занимают около 240 тыс. символов контекста, это слишком много
  для небольшой модели. В замере было 18 — набор для Бухгалтерии 3.0 из
  [инструкции по подключению](CONNECTING.md#меньше-инструментов-для-модели-опционально), там же набор для Управления
  торговлей. 18 инструментов с инструкциями — около 12 тыс. токенов на каждый запрос.
- **Контекст.** Я ставил 32 768 токенов. LM Studio оценивала память под модель с таким контекстом примерно в 7,3 ГБ.
- **Клиент с поддержкой MCP.** LM Studio умеет это сама. Ollama — через клиент, который подключает MCP-серверы.
- **Называть в просьбе всё, что нужно для документа.** Отдельно я проверял, какой инструмент записи выбирает эта
  модель. Если в просьбе не было товара, количества или склада, она не вызывала инструмент, а переспрашивала. Это
  правильное поведение, но это лишний круг. Когда те же шесть просьб содержали всё нужное, первым вызовом был верный
  инструмент во всех 12 попытках. Инструменты при этом только выбирались, в базу ничего не писалось.

## Повторить на своём компьютере

Скрипты лежат в [scripts/bench](../scripts/bench). Нужны Python 3 и клон репозитория; тестовый сервер берёт описания
инструментов из `manifest.json`, настоящая база и `.env` не нужны. Результаты пишутся в `scripts/bench/out/`.

Локальная модель: загрузите модель в LM Studio, включите локальный сервер и запустите два прогона.

```bash
python3 scripts/bench/lm.py 2 qwen3.5-9b
```

Облачные модели — по желанию; они тратят лимиты вашей подписки. Нужен вход в программу и имя модели:

```bash
CLAUDE_MODEL=claude-sonnet-5-5 python3 scripts/bench/claude.py 3
```

```bash
CODEX_MODEL=gpt-6-luna python3 scripts/bench/codex.py 3
```

Если программа не находится по имени, укажите путь в `CLAUDE_BIN` или `CODEX_BIN`. Codex запускается без вашего
файла настроек, с отключёнными командной строкой, браузером, управлением компьютером и плагинами; Claude — только с
тестовым сервером и без встроенных инструментов. Сводка:

```bash
python3 scripts/bench/summary.py
```

Получили другие цифры на своём железе — напишите в [issues](https://github.com/evilbruce666/1c-odata-mcp/issues),
это полезнее моей таблицы.
