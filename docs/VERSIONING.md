# Версии и совместимость

Версии — по [семантическому версионированию](https://semver.org/lang/ru/): с 1.0.0 то, что ниже названо публичным
API, меняется несовместимо только в новой мажорной версии (2.0.0). Новые инструменты, параметры и поля ответов
добавляются в минорных версиях, исправления — в патчах.

## Публичный API — не ломается без 2.0

- **Имена инструментов и сценариев** (`read.*`, `write.*`, prompts) и смысл каждого.
- **Параметры инструментов:** имя, тип, обязательность, значения по умолчанию. Новый параметр — только
  необязательный, с прежним поведением по умолчанию.
- **Поля ответов** (`structuredContent` по `outputSchema`): существующие поля не удаляются и не меняют тип; новые
  поля могут появляться — клиент должен их пропускать.
- **Виды ошибок** в `_meta["odata-1c/errorKind"]`: `auth`, `not_found`, `not_published`, `bad_request`, `input`,
  `refused`, `rate_limit`, `server`, `timeout`, `network`, `parse`, `busy`, `cancelled`, `deadline`, `overflow`,
  `unknown`, `internal`. Новый вид может появиться; смысл существующих не меняется.
- **Гарантии записи:** предпросмотр перед записью, `operationId` и повтор подтверждения без дубля,
  `write.operation.status` для операций с неизвестным исходом, документы создаются непроведёнными.
- **Переменные окружения** из [.env.example](../.env.example): имя, смысл и значение по умолчанию. Значение по
  умолчанию, которое расширяет права (запись, сеть), не меняется никогда.
- **HTTP-транспорт:** адреса `/mcp` и `/healthz`, заголовок `Authorization: Bearer`.
- **Журнал записи:** каталог журнала, созданный версией 1.x, читается всеми версиями 1.x — обновление не теряет
  операции с неизвестным исходом.

## Не публичный API — может меняться в любой версии

- Тексты сообщений, заметок (`notes`, `note`) и читаемого вида предпросмотра (`view`): их показывают человеку, а
  программа опирается на поля и вид ошибки.
- Состав `payload` в предпросмотре: это то, что уйдёт в 1С, и он следует за конфигурацией 1С.
- Число и порядок запросов к 1С, внутренние модули, скрипты `npm run test:live*` и `probe:*`.
- Поведение для конфигураций вне [заявления о поддержке](SUPPORT.md) (КА 2, ERP 2, доработанные базы).
- Отказ там, где раньше создавался документ, который 1С проводит неверно или не проводит: это исправление, а не
  поломка, и оно идёт в минорной или патч-версии с записью в «Что изменится при обновлении».

## Устаревшие имена

Устаревшее имя инструмента или параметра работает до следующей мажорной версии, а в описании инструмента сказано,
чем его заменить. Сейчас устаревшие:

| Имя | Замена | Удаляется |
|---|---|---|
| `read.accounting.get_contract_settlement_settings` | `read.accounting.get_settlement_settings` со `scope=contract` | 2.0 |
| `write.accounting.set_contract_settlement_settings` | `write.accounting.set_settlement_settings` со `scope=contract` | 2.0 |

## Какие версии поддерживаются

Исправления ошибок и уязвимостей выходят для последней минорной версии 1.x. Версии 0.x после выхода 1.0.0 не
поддерживаются: обновитесь до 1.x — что изменится при обновлении, сказано в [CHANGELOG](../CHANGELOG.md).
